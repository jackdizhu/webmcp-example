# 规则索引

本目录存放 `webmcp-example` 工程的自定义规则。AI 代理与开发者在开发前应阅读以下规则。

## 规则列表

| 文件            | 适用范围           | 说明                             |
| --------------- | ------------------ | -------------------------------- |
| language-rules.md | 所有代码与文档     | 输出语言、编码、注释、格式化规范 |
| project-rules.md  | 全工程开发         | 技术栈、命令、架构、文件大小约束 |
| design_rules.md   | 设计类任务         | 多方案比选、多维评估、确认流程、变更分级 |
| issues_rules.md   | 全部对外输出       | 个人信息与敏感信息脱敏规则        |

## 优先级

> 工程级规则 < 仓库级规则（`AGENT.md`） < 用户/工作区规则

若本目录规则与上级规则冲突，以上位规则为准。本目录用于沉淀该工程特有的约定，避免在其他项目间通用规则中造成噪音。
