# 语言规则

适用于 `webmcp-example` 工程的所有源代码、文档与注释。

## 1. 输出语言优先级

- **优先使用中文**：代码注释、文档、提交说明等优先使用中文，便于阅读与维护。
- **技术术语保留英文**：如 `WebMCP`、`MCP`、`registerTool`、`polyfill` 等专有名词保留原文。
- **错误提示**：用户可见的异常、日志提示信息使用中文。

## 2. 编码规范

- **文件编码**：所有文件使用 UTF-8 编码，避免中文乱码。
- **注释**：以中文为主，标识符、变量名、函数名使用英文（语义直白，避免缩写）。
- **JSON / YAML**：确保 UTF-8 编码，含中文时保持正确转义。

## 3. 多语言处理

- 根据用户输入语言自动切换响应语言；本工程默认中文。
- Markdown 文档以 UTF-8 保存；日志输出注意终端编码一致（Windows 下建议 `chcp 65001`）。

## 4. 代码风格

> 已整合至 `coding-style.md` §2.1「通用代码质量规范」（命名、注释结构、文件大小等代码写法规则统一在该文件维护）；本文件只保留语言、编码与注释语言层面的规则。
