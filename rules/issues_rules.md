# 个人信息脱敏规则

> **适用范围**：适用于 webmcp-example 的全部对话回复、代码注释、日志、文档、终端输出。涉及跨层契约、工具 schema、密钥/凭据相关内容时，须同时遵循 `rules/design_rules.md`。

## 0. 优先级原则

### 0.1 最高优先级
- **安全脱敏**：禁止泄露任何隐私信息与系统真实路径
- **强制覆盖**：本规则与其它规则冲突时，以本规则为准
- **主动执行**：无需用户提醒，输出内容时自动进行脱敏

---

## 1. 适用范围

本规则适用于所有对话回复、代码注释、日志、文档、终端命令输出、错误信息等一切对外可见内容。

**禁止以"便于定位问题""临时参考"等理由保留敏感明文。**

---

## 2. 敏感数据分类

### 2.1 个人信息（PII）
- 姓名、昵称、网名
- 手机号、座机号
- 身份证号、护照号、社保号
- 邮箱地址
- 家庭住址、工作单位地址
- 出生日期、年龄
- 照片、指纹、人脸等生物特征信息
- 婚姻、健康、财务状况等隐私数据

### 2.2 账号标识
- 用户名、登录名
- 平台用户 ID（如 open_id、user_id、session_id）
- 项目 ID、工单 ID 等内部编号（脱敏后保留尾号用于区分）
- 设备号、设备序列号

### 2.3 密码与凭据
- 登录密码
- PIN 码
- 验证码

### 2.4 密钥与令牌
- API Key / API Secret
- Access Key / Secret Key
- 访问令牌（Token、JWT、Access Token、Refresh Token）
- 私钥（RSA/SSH 私钥）、证书私钥
- 数据库连接串中的用户名密码
- 授权码、会话密钥

### 2.5 电脑真实文件路径
- 盘符路径（如 `c:\...`、`d:\...`）
- 用户主目录真实路径（如 `C:\Users\<真实用户名>\...`）
- 包含用户名的项目目录、工作区路径
- 服务器绝对路径、内网共享路径

### 2.6 网络与设备信息
- IP 地址（公网/内网）
- 端口号、内网域名
- MAC 地址
- 主机名、机器名

### 2.7 环境与配置敏感项
- `.env` 等配置文件中的真实值
- 环境变量中的 Key/Secret
- 各类配置（如 MCP 服务器、构建产物）中的凭据与 Token

---

## 3. 脱敏规则

### 3.1 掩码规则

| 数据类型 | 掩码方式 | 示例 |
|---------|---------|------|
| 姓名 | 保留姓氏，名字用 `*` | `张**` |
| 手机号 | 保留前 3 后 4 位 | `138****5678` |
| 身份证号 | 保留前 4 后 4 位 | `1101**********1234` |
| 邮箱 | 保留首字母与域名 | `j***@example.com` |
| 地址 | 保留到市级，其余用 `*` | `北京市朝阳区****` |
| 账号/ID | 保留前 2 后 2 位 | `us****er` |
| 密码 | 全部掩码 | `********` |
| 密钥/Token | 保留前 4 后 4 位 | `sk-****-****-abcd` |
| 私钥 | 全部掩码 | `-----BEGIN ... **** -----END-----` |
| 文件路径 | 保留文件名，替换真实目录 | `<用户目录>/.../file.txt` |
| IP 地址 | 替换末段 | `192.168.***.***` |
| 端口 | 按需掩码 | `http://127.0.0.1:****` |

### 3.2 路径脱敏约定
- 禁止输出真实盘符与用户主目录，统一使用占位符：
  - 用户主目录 → `<用户主目录>` 或 `%USERPROFILE%`
  - 项目根目录 → `<项目根目录>` 或 `<PROJECT_ROOT>`
  - 盘符 → `<盘符>`
- 示例：`c:\global-user-data\ai-workspace\foo\bar.py` → `<用户主目录>\ai-workspace\foo\bar.py` 或 `<项目根目录>\foo\bar.py`

### 3.3 场景化脱敏
- **对话回复**：涉及任何敏感信息时一律脱敏后输出
- **代码示例**：使用占位符（如 `<token>`、`<password>`、`<api_key>`）替代真实值
- **日志/报错**：敏感信息用 `***` 或 `****` 掩码
- **终端命令**：命令中出现的真实路径、账号、密钥必须脱敏
- **文档/设计稿**：引用本地路径时使用占位符

## 4. 输出约束

### 4.1 默认脱敏
- 只要内容可能包含敏感信息，一律先脱敏再输出
- 不确定是否敏感时，按敏感处理

### 4.2 允许明文的情况（需满足全部条件）
- 信息由用户本人主动提供且明确要求展示
- 属于当前任务必要信息，且不涉及他人隐私与系统凭据
- 不包含密钥、密码、Token 等高风险数据

### 4.3 禁止行为
- ❌ 禁止在代码注释中写入真实密钥、密码、Token
- ❌ 禁止将 `.env`、配置文件原样输出
- ❌ 禁止在示例中复用真实账号、真实 ID、真实路径
- ❌ 禁止"脱敏后仍能逆向还原"的弱掩码（如只删一位）

---

## 5. 检查与验证

### 5.1 输出前自检清单
- [ ] 是否包含真实文件路径（盘符/用户目录）？
- [ ] 是否包含密钥、Token、密码？
- [ ] 是否包含账号、ID、邮箱、手机号？
- [ ] 是否包含 IP、端口、内网地址？
- [ ] 掩码是否符合第 3 节规则？

### 5.2 违反处理
- 发现泄露敏感信息时，立即停止输出，改用脱敏表述
- 用户指出脱敏不当时，主动说明并修正，不辩解
